MCP nima?

Model Context Protocol — Claude yoki ChatGPT-ga ushbu loyihaning suratlar, videolar va avatar yaratish imkoniyatlarini "vositalar" sifatida beradi. Ulangach, shunchaki oddiy so'zlar bilan so'rasangiz bo'ldi: "meniki uchun quyosh botayotgan sohilda video yasab ber" — narxni birinchi ko'rsatadi, tasdiqlagandan keyingina pul sarflaydi.

1

Claude Desktop

mcp/server.py faylini yuklab oling, so'ng quyidagi blokni claude_desktop_config.json fayliga qo'shing va Claude Desktop-ni qayta ishga tushiring.

server.py yuklab olish

Fayl joylashuvi: macOS'da ~/Library/Application Support/Claude/claude_desktop_config.json, Windows'da %APPDATA%\Claude\claude_desktop_config.json

2

Claude Code

Terminalda ushbu buyruqni ishga tushiring (avval yuqoridagi tugma orqali server.py-ni yuklab oling).

3

Masofaviy ulanish (claude.ai brauzerda, Claude Desktop yoki ChatGPT)

Kompyuteringizga hech narsa o'rnatmasdan ulanishning yo'li: claude.ai saytida (brauzerda) yoki Claude Desktop ilovasida — Settings → Connectors → Add custom connector; ChatGPT'da ham xuddi shu yo'l — Settings → Connectors → Add custom connector. Bitta manzil hammasiga ishlaydi, chunki ular bir xil masofaviy MCP protokolini gapiradi.

Ulanish qadamlari ilova versiyasiga qarab biroz farq qilishi mumkin — aniq qadamlar uchun Claude yoki ChatGPT'ning joriy sozlamalar bo'limiga qarang.
